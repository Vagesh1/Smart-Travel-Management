
# Smart Travel Management

A custom ServiceNow application designed to manage employee travel information and travel-related processes.

## Project Overview

Smart Travel Management is developed on the ServiceNow platform using a custom scoped application.

**Application Name:** Smart Travel Management  
**Application Scope:** `x_688229_smart_t_0`  
**Platform:** ServiceNow  
**Development Environment:** ServiceNow PDI  
**Local Development:** ServiceNow SDK  
**Version Control:** Git and GitHub

## Existing Application Components

The current application metadata includes:

- Custom travel details table
- Caller and destination fields
- Travel type and travel dates
- Passport and visa detail fields
- Business Rules
- Client Scripts
- UI Policies and UI Policy Actions
- UI Actions
- Application Modules
- User Roles and Access Control Lists
- Reports and Dashboards

## Technology Stack

- ServiceNow Platform
- JavaScript
- GlideRecord
- Glide APIs
- ServiceNow SDK
- Node.js and npm
- Visual Studio Code
- Git and GitHub

## Development Approach

The application is maintained using ServiceNow SDK for local development and Git for version control.

Development activities include:

1. Application configuration and metadata management.
2. Server-side and client-side scripting.
3. Form customization and validation.
4. Access control and application security.
5. Testing and debugging.
6. Version control and change management.

## Security

- Do not store actual employee passport or visa information in source control.
- Do not commit passwords, API keys or access tokens.
- Use dummy data for development and demonstrations.
